How this page works with WordPress

The landing page is a self-contained HTML folder that sits next to WordPress on the same domain. WordPress keeps running exactly as it does today. Nothing in WordPress, the theme or any plugin is changed.

✔ What works

  • Same domain, exact URL for Google Ads: /boat-transport-florida/
  • Design is identical to the approved page (desktop + mobile)
  • All photos, buttons, quote form, phone links, FAQ accordion
  • Page title, meta description, canonical URL and Google schema are built in, so Google indexes it normally
  • Google Tag Manager + Google Ads tags are already inside (same IDs as the rest of the site)
  • Leads arrive by email; the visitor lands on a thank-you page

✖ What does not sync

  • It is not listed under WordPress → Pages and does not open in Elementor
  • Changes to the WordPress menu or footer do not update on this page (its header and footer are copies)
  • Yoast / Rank Math do not see it; it is not in the WordPress sitemap
  • Text edits are made in the HTML file (or send the change to Yasir, who rebuilds and re-uploads in minutes)
  • Text-message (SMS) alerts are not available with the email form

Why this approach

The goal is to launch the Google Ads campaign now. This folder goes live in 5 minutes with no risk to the existing site. Rebuilding the same design inside Elementor takes about a day, will not be pixel-exact, and becomes throwaway work if the new website replaces WordPress.

Decision needed: Is WordPress staying long-term, or is the new website replacing it?
Staying → we build this page again inside Elementor so it is fully editable in WordPress. Being replaced → upload this folder now and launch the ads; the page moves to the new site automatically at launch.

Step 1 · 5 minutes

Upload to Hostinger

Done through the Hostinger File Manager. No FTP program needed.

  1. Log in to Hostinger → hPanel → Websites → mccboundlegends.com → Manage.
  2. Left menu → Files → File Manager.
  3. Open the folder public_html/. You will see WordPress there (wp-admin, wp-content, wp-includes). Do not touch those.
  4. Click Upload (top-right) and upload boat-transport-florida-upload.zip into public_html/.
  5. Right-click the zip → Extract → extract into the current folder. Then delete the zip.
  6. Check the result. You must now have:
    public_html/boat-transport-florida/index.html
    public_html/boat-transport-florida/images/ (15 files)
    public_html/boat-transport-florida/thank-you/index.html
  7. Open https://mccboundlegends.com/boat-transport-florida/ in a browser. The page is live.
If you see a WordPress "Page not found" instead:
  1. hPanel → Advanced → Cache Manager → purge / clear cache (LiteSpeed).
  2. WordPress admin → Pages → search "boat-transport-florida". If a WordPress page with that slug exists, rename its slug.
  3. Reload. A real folder always wins over a WordPress permalink once the cache is cleared.

Rollback

Delete the folder public_html/boat-transport-florida/. WordPress is untouched.

Step 2 · 3 minutes

Activate the quote form

The form sends leads by email through FormSubmit (free, no plugin, no API key). It needs one activation click.

  1. On the live page, fill in the quote form with test details and submit it.
  2. FormSubmit emails Jeff.c@mccboundlegends.com a message titled "Activate form". Check spam if it is not in the inbox. Click the activation link once.
  3. Submit the form again. The lead now arrives as a clean table email with: Year/Make/Model, boat type, length, pick-up ZIP, drop-off ZIP, trailer, date, name, phone, email, SMS consent.
  4. After submitting, the visitor lands on /boat-transport-florida/thank-you/.

To send leads to a different address: open index.html, find the line action="https://formsubmit.co/Jeff.c@mccboundlegends.com" and change the email. Re-activation is needed for a new address.

Step 3 · 10 minutes

Google Ads conversion tracking

The page already loads Google Tag Manager GTM-M44WB2FK and the Google Ads tag AW-18234011636. It sends three events that GTM turns into conversions:

EventWhen it firesUse it as
phone_clickAny phone number is tapped/clicked (header, hero, routes, bottom bar)Conversion: Phone Click
quote_submitThe quote form is submittedConversion: Quote Form Submit
generate_leadThe thank-you page loadsBackup conversion (page load)
  1. Google Ads → Goals → Conversions → + New conversion action → Website → "Add a conversion action manually". Create Quote Form Submit (Submit lead form, count One) and Phone Click (Contact, count Every). Choose "Use Google Tag Manager" and copy each Conversion label.
  2. Google Tag Manager → container GTM-M44WB2FK → Admin → Import Container → file mcc-gtm-sitewide-conversions.json (supplied) → Existing workspace → Merge.
  3. Variables → paste the two labels into Const – Label: Quote Submit and Const – Label: Phone Click.
  4. Click Preview, open the live page, tap the phone number and submit a test quote. Both tags show as fired. Click Publish.
  5. Within a few hours Google Ads shows the conversions as "Recording conversions". Launch the campaign.

The same events exist on the new website, so this GTM setup keeps working after the site moves, on every page, not just the boat page.

Before the ads go live

Launch checklist

Test on a computer and on a phone. Every item must pass.

  • Page loads at https://mccboundlegends.com/boat-transport-florida/ with no WordPress header around it
  • Browser tab reads: Boat Shipping to Florida — Free Quote | MCC Bound Legends
  • Quote form submitted → activation link clicked → second test lead arrives by email
  • Phone number tapped on a phone → dialer opens with (888) 785-0028
  • Orange sticky bar visible at the bottom on mobile; both buttons work
  • Every "Get a Quote" button on the page scrolls to the form (boat types, routes, price cards, bottom band)
  • FAQ questions expand and collapse when clicked
  • USDOT 4464266 / MC 1760960 shown in the top bar, hero photo and footer
  • Copyright at the bottom says 2026
  • PageSpeed (pagespeed.web.dev) mobile score above 70; take a screenshot
  • Google Ads shows both conversions recording after the test submit

Things to confirm on the content

  • "BBB Accredited" appears in the hero trust strip and footer (from the supplied copy). If MCC is not BBB accredited, tell Yasir and it is removed.
  • Prices $1,500 – $5,000+ by boat size, as supplied.
  • Reviews are the four real boat-transport reviews from Google and Trustpilot (Christopher Smith, Malik, Anna Carlson, Emmanuel Rosario), quoted as published.

Making changes later

Send the change (text, photo, price) to Yasir. The page is generated from a master copy, so any edit is rebuilt and the new zip re-uploaded the same way as in Step 1. Replacing the folder keeps the URL, tracking and form unchanged.
