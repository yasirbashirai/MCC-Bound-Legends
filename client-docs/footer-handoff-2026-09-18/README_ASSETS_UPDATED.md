- `00_REFERENCES/` – approved desktop and mobile footer reference images

- `02_BACKGROUND_ASSETS/` – skyline/water CTA backgrounds
- `03_TRUCK_YACHT_ASSETS/` – truck and yacht imagery

## Build note for developer
Do not build the footer as one flat image. Build all text, buttons, links, contact info, navigation, and mobile accordions in live HTML/CSS. Use the supplied visual assets for logo, scenic backgrounds, truck/yacht photography, and badge graphics.
